# Robin_Dual_Ant_ESC-6-24V_2-6S_3.6A
This ESC is designed for 150g Ant weight combat robots, to drive N20 and N10 brushed motors. It supports internal mixing and overhead driving. The ESC is designed to be used with 2-6S, and a maximum current of 3.6A. The internal BEC can supply up to 100mA for a receiver. The PCB is 22x22mm and weighs 2.3g.
